# axlk78.github.io

Personal portfolio of Axel Kifani: a map of my home lab, and one case file per project.

- `index.html`: home page (lab map, key figures, case index, logbook, contact)
- `cases/*.html`: one case file per project
- `assets/js/map.js`: lab map nodes and side-panel content
- `assets/css/site.css`: dark "console" for the home page, bone-white "paper" for case files

Static HTML, CSS and JS: no build step, no tracking. Hosted on GitHub Pages.

Preview locally:

```bash
python3 -m http.server 8000
```
